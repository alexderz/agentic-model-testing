      How the work evolved

        Method: one task per test, no guidance, a sealed container that reaches only the model server and a recorded Home Assistant; graded by running the result, never by reading it.

        Caveats

            Rendered from data/bakeoff.json; the page loads no script, font or image from anywhere but this site. A model-written piece runs only after you press “Play live”, alone, in an iframe sandboxed to scripts (no same-origin access, navigation, pop-ups or forms), served byte for byte and unloaded when the viewer closes. Pagoda pages fetch three.js from cdn.jsdelivr.net and some fetch Google Fonts, inside that sandbox only.
