The field

Speed, quality, context and offload

Speed is set by how much of the model sits in VRAM. Models that fit the GPU ran at 25 to 150 tok/s; models that keep experts in system RAM ran at 3 to 25 tok/s, whatever their size. The engine moves a model within its tier by 2 to 5 times.

Test 3 · subagents

Use an MCP server through a subagent, and fix it

The model gets an MCP server's source and a probe subagent whose only tools are that server's. It must get 14 facts through the probe, check them against the REST API, and fix the server if it is wrong. 3G gives it a known-good server, 3O its own server from test 2. Rubric: six items scored 0-2 from the transcript (brief, sizing, structured output, checking, handling a failing probe, trust-or-fix decision).
